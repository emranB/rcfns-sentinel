# Rules

## Python

- Top-of-file comments use `'''` notation. All other comments use `#`.
- Prefer dataclasses for grouped state. Name each dataclass for the data it holds.
- Do not prefix function names with `_`.
- Use `tabulate` whenever printing structured info to the screen.
- Use short `#` inline comments for complex logic.
- Every function must have a `#` comment immediately before its definition explaining what it does.
